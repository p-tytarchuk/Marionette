The motion data sorted into the four body classes of the skeleton spec (biped, quadruped, winged, limbless) plus other: how many clips each class has, how many can be used now, and which movements their captions describe. Click a class for its details.

2D (Lottie) clips, tokenised, by the body plan Qwen found

A clip counts for a mode when its motion caption mentions it (keyword rules, so a count is "mentions the mode", not a verified label); one clip can count for several modes. Usable means the clip's character was normalised and passed the checks of the inventory; for winged, limbless and other that is almost always because the character was never normalised (the panel shows the reasons), so none of their clips can be played on a character yet. Marine bodies are counted as limbless. The Lottie side only knows 2-leg and 4-leg bodies (Qwen's label); it has no winged or limbless class yet. Numbers come from data/inventory/clips.csv and data/embeddings/lottie_feats_index.csv (scripts/motion/motion_coverage.py).
